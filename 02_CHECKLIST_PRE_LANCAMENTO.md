# Checklist pré-lançamento — DBD Multi Overlays

## Bloqueios que impedem vender

- [ ] Receber autorização escrita aplicável da Behaviour Interactive ou concluir alternativa de produto independente juridicamente revisada.
- [ ] Confirmar com Tributos Mobiliários de Barueri o enquadramento da licença de software vendida por pessoa física.
- [ ] Consultar contador sobre IRPF, ISS, habitualidade, cadastro municipal e documento fiscal.
- [ ] Confirmar com o banco que a conta/chave Pix pode receber pagamentos da atividade e verificar eventuais tarifas.

## Oferta comercial

- [x] Município informado: Barueri/SP.
- [x] Modalidade pretendida: pessoa física.
- [x] Meio de pagamento: Pix somente.
- [x] Emissão de licença: manual/offline.
- [x] Duração pretendida: perpétua, sem expiração por calendário.
- [x] Dispositivos: 1 computador ativo por vez.
- [x] Suporte: Discord.
- [ ] Definir preço em reais.
- [ ] Definir se a licença inclui atualizações futuras e até qual escopo.
- [ ] Definir transferência para outro computador e reinstalação após formatação/troca de hardware.
- [ ] Criar servidor Discord e convite oficial.
- [ ] Definir prazo e horário realista de suporte.

## Documentos

- [ ] Preencher nome/identificação do fornecedor e contato público adequado.
- [ ] Revisar EULA com profissional.
- [ ] Auditar machine ID, dados locais, conexões de rede, logs e diagnósticos antes de finalizar o Aviso de Privacidade.
- [ ] Finalizar política Pix, entrega e reembolso.
- [ ] Publicar documentos apenas depois das revisões.

## Produto e entrega

- [ ] Testar instalador em Windows limpo, sem ferramentas de desenvolvimento e sem cache dos helpers.
- [ ] Testar detecção automática, GDI 8 FPS/125 ms e Alt+Tab no pacote instalado.
- [ ] Testar licença válida, inválida e vinculada a outra máquina.
- [ ] Testar atualização, desinstalação e preservação de configurações.
- [ ] Criar repositório GitHub exclusivo de downloads.
- [ ] Preparar Release com instalador, notas e SHA-256.
- [ ] Verificar novamente o download publicado.

## Operação

- [ ] Preparar chave/QR Pix sem exposição pública desnecessária de CPF/telefone.
- [ ] Criar planilha privada de pedidos.
- [ ] Proteger chave privada Ed25519 com backup seguro.
- [ ] Fazer uma simulação completa de pedido sem cobrar terceiros.
- [ ] Preparar mensagens de pagamento, ativação, entrega e suporte.

**Não abrir vendas enquanto qualquer bloqueio da primeira seção estiver pendente.**
